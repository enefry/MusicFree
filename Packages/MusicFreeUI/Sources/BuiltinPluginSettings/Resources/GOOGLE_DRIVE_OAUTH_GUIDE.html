What you will create

The only value you paste into MusicFree is a public Client ID:
xxxxxxxx.apps.googleusercontent.com

An iOS app cannot keep a client secret confidential. MusicFree does not need one, and you should never add one to the project.

01Cloud project

Create or select a project

  1. Open Google Cloud Console and sign in with the account that will manage OAuth.
  2. Tap the project selector at the top, then choose an existing project or create a new one.
  3. You can name it MusicFree Drive. Keep this project selected for every remaining step.

02API Library

Enable Google Drive API

  1. Open the console menu, then go to APIs & Services → Library.
  2. Search for Google Drive API.
  3. Open it and tap Enable. When the button changes to Manage, this step is complete.

You do not need an API key or the Google Picker API.

B. Audience and test users

  1. Choose External for personal Gmail accounts or users outside your Workspace organization.
  2. Keep Publishing status set to Testing.
  3. Under Test users, tap Add users and add every Google account that will sign in on the device.
This is the allowlist. A project administrator is not automatically a test user. If the device account is missing, Google commonly returns Error 403: access_denied.

C. Data Access

MusicFree browses and downloads files. It does not upload, rename, or delete them, so add only this read-only scope:

https://www.googleapis.com/auth/drive.readonly
  1. Open Data Access and tap Add or remove scopes.
  2. Search for the scope above, or add the full value manually.
  3. Tap Update, then Save. Do not replace it with the broader drive scope.

05Local Xcode project

Add the local OAuth configuration

From the repository root, copy the example. The new local file is ignored by Git.

cp GoogleDriveOAuth.local.xcconfig.example GoogleDriveOAuth.local.xcconfig

Replace the placeholders with the values from the iOS client:

GOOGLE_DRIVE_OAUTH_ENABLED = YES
GOOGLE_DRIVE_OAUTH_CLIENT_ID = 1234567890-abcdef.apps.googleusercontent.com
GOOGLE_DRIVE_OAUTH_REVERSED_CLIENT_ID = com.googleusercontent.apps.1234567890-abcdef
GOOGLE_DRIVE_OAUTH_URL_SCHEME = $(GOOGLE_DRIVE_OAUTH_REVERSED_CLIENT_ID)
GOOGLE_DRIVE_OAUTH_REDIRECT_URL = $(GOOGLE_DRIVE_OAUTH_URL_SCHEME):/oauth2redirect/google
The callback must match exactly:
REVERSED_CLIENT_ID:/oauth2redirect/google
It uses a colon and one slash (:/), not the double slash used by web URLs.

If the Xcode project was regenerated, confirm that basic_config.xcconfig still contains:

#include? "GoogleDriveOAuth.local.xcconfig"
06Connect in MusicFree

Build, install, and sign in

  1. Rebuild and install MusicFree. An older installed build will not contain the new callback URL scheme.
  2. Open Settings → Online Sources → Add Google Drive.
  3. Enter a source name and paste the same original OAuth Client ID. Do not paste the reversed ID or a client secret.
  4. Start the connection and choose an account already listed under Test users.
  5. Approve read-only Drive access. The browser should return to MusicFree, where you can browse folders and download files.

Use these

  • An iOS Client ID
  • …apps.googleusercontent.com
  • An allowed test account
  • drive.readonly

Do not use

  • An API key
  • A Desktop or Web client
  • A client secret
  • A service-account private key

Common errors

403 access_denied or “app is being tested”
Open Google Auth Platform → Audience → Test users and add the exact Google account selected on the device. Project administrators and test users are separate roles.
redirect_uri_mismatch
Confirm that the client type is iOS, the Bundle ID is win.tools4me.music, and the reversed ID belongs to the same Client ID. The callback must be REVERSED_CLIENT_ID:/oauth2redirect/google.
invalid_client
The app may have received an API key, reversed ID, or the wrong client type. Paste the original Client ID ending in .apps.googleusercontent.com.
Authorization does not return to MusicFree
Rebuild and reinstall the app, then verify that the built Info.plist contains the reversed Client ID as a URL scheme. Editing xcconfig does not update an already installed build.
Files are missing or downloads fail
Verify that Google Drive API is enabled and that the authorization uses drive.readonly. If needed, revoke the old grant in your Google Account and reconnect from MusicFree.
Do I need to publish or verify the app?
For small private tests, keep the app in Testing and use the test-user allowlist. To serve accounts outside that list, move to Production. Google may then require a homepage, privacy policy, authorized domain, and verification for the Drive scope.

Credential safety
A Client ID is public; a refresh token is sensitive. MusicFree stores OAuth tokens in the system Keychain. Never place authorization codes, access tokens, refresh tokens, client secrets, or service-account private keys in xcconfig, screenshots, issues, or Git.
