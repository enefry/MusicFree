AE/RMSE 仍不是“设计正确性”的单一判定：状态栏时间、系统状态栏图标、SF Pro 字体度量、系统 Tab Bar 阴影和真实字体抗锯齿都会放大像素差异。Track Detail 的 AE 还包含运行截图中被半透明 Tab Bar 遮住的额外技术字段，而 Figma 只保留当前可读字段。结构、主要几何、颜色、Artwork、操作按钮和导航层级已按运行态校准；最终字体像素验收仍需在 Figma Desktop 使用 SF Pro/SF Symbols 打开 `07 Visual QA` 完成。
