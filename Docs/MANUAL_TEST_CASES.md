## 2. 当前能力边界

### 2.1 当前生产入口已接通

- 本地文件和文件夹选择、共享 Documents 自动补扫、哈希去重、元数据/封面读取、托管存储。
- 资料库歌曲、收藏、最近播放、专辑、艺人、流派、文件夹、搜索、刷新和分页。
- 歌单创建、重命名、删除、详情、排序、移除和播放命令；详情页从资料库分页加载候选，以真实标题/时长展示并支持搜索、多选添加。
- 歌曲、收藏和播放历史中的单曲，以及专辑/流派集合，可选择已有播放列表或新建目标后添加；重复成员会被过滤，整组添加保持稳定歌曲顺序。
- 基础播放、暂停、上一首、下一首、seek、音量、静音、队列、随机、重复、默认倍速。
- 后台音频声明、锁屏信息、系统播放命令、中断和输出路由事件处理。
- 设置保存/恢复、存储统计/维护、版本、第三方许可和诊断信息。

### 2.2 必须按“保存意图，不代表生效”验收

当前 App 向播放引擎开放 `seek`、`variable rate` 和运行时 EQ。EQ 可见并通过 `VLCAudioEqualizer` 应用，但真机可听结果仍需专项验收。以下能力暂时隐藏且不得被宣称已生效：

- ReplayGain。
- 无缝播放。
- 淡入淡出。

### 2.3 当前构建限制

- 播放器“分享”已接通系统 `ShareLink`，当前只分享“标题 - 艺人”（无艺人时只分享标题）文本，不分享媒体文件、封面或可播放链接；播放器内技术详情仍未接通。
- 歌词和播放器内 AirPlay 图标当前禁用；系统控制中心的输出路由另行测试。
- 流派和文件夹均已支持下钻到对应歌曲列表；真实大资料库分页、空态和导航恢复仍需设备验收。
- 歌曲列表在正式 App 中点击即播放，当前不从该入口进入 `LibraryTrackDetailView`。
- 歌曲列表的歌曲菜单提供资料库删除入口；删除会移除资料库记录和 App 托管副本，不删除共享 Documents 中的原始文件。
- 不支持 Apple Music、云同步、播客、电台、CarPlay、Siri、M3U 导入导出、服务端歌单、Ampache/Subsonic 和视频界面。

发现实际行为与以上边界不一致时，先记为缺陷或产品范围漂移，不得自行改写预期。
