# 详情页信息与编辑增强

## 页面范围

参考 `Design/详情页增强` 的信息项，沿用现有 UIKit 导航、颜色、字体、专辑网格和分组表单。

| 页面 | 显示与编辑 |
| --- | --- |
| 歌曲 | 主要艺人、其他艺人、作曲者、专辑、专辑艺人、流派、年份、曲目号、碟片号、内容分级、评论、歌词和封面 |
| 专辑 | 名称、主要艺人、其他艺人、简介、发行日期、年份、流派、碟片数量、格式、专辑类型、唱片公司、版权和封面 |
| 艺人 | 名称、国家 / 城市、出生日期、简介和头像 |

歌曲详情另外显示只读的文件信息：时长、容器、编码、文件大小、采样率、位深、声道、比特率、真实添加日期、来源、存储位置、文件名和文件夹，以及播放次数和上次播放时间。

专辑总曲目数和总时长、艺人歌曲数和专辑数由现有资料库计算。未知信息明确显示为未知，不生成猜测值。专辑流派首次编辑时从歌曲读取，之后使用保存的专辑值；清空后不会再次自动填回。日期通过系统开关启用，可关闭以清除。

歌曲详情的编辑按钮，以及专辑、艺人详情右上角菜单，均可打开编辑表单。艺人页面保留现有专辑分组和播放操作；从艺人页面进入单个专辑时也支持专辑信息与编辑。

## 保存约定

- 修改保存到 App 资料库，不改写原始音频文件标签。
- 新增详情字段为可选 Codable 数据，旧资料库可继续读取。
- 歌曲和专辑更新请求未提供新增详情时保留已有值；明确提供空详情时清除值。
- 收藏、播放统计、关系更新、专辑合并及来源扫描保留新增详情。
- 艺人编辑保留原有 ArtistID，维持歌曲和专辑关联；后续歌曲编辑保留艺人头像与简介。
- 选择图片时使用现有图片解码与缓存流程，保存事务失败时清理新写入的封面资源。
- 当前使用静态封面；参考图中的竖版封面、动态封面和自定义背景色不在此次信息编辑增强范围内。
