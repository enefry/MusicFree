# 本地播放器功能 Review

审查日期：2026-08-15<br>
审查基线：`main` / `df6c120`；实现分支：`codex/musicfree-p1`<br>
目标：补齐本地音乐播放器的日常使用闭环，区分已实现、未接通和明确不在范围内的功能。

## 当前已实现

- 本地文件和文件夹导入、Documents 自动补扫、内容哈希去重、元数据和封面读取。
- 歌曲、收藏、播放历史、专辑、艺人、流派和文件夹浏览。
- 搜索、排序、分页、刷新，以及专辑/艺人/集合详情页的歌曲操作。
- 歌单创建、重命名、删除、添加/移除歌曲和排序。
- 播放队列、播放/暂停、上一首/下一首、拖动进度、音量、静音、随机和重复。
- 播放速度、运行时均衡器、睡眠定时器、后台音频、锁屏 Now Playing 和系统远程控制。
- 单曲删除、集合歌曲批量删除；删除会移除资料库记录和 App 托管副本，但保留共享 Documents 原文件。
- 歌词读取、歌词编辑、时间轴高亮、自动滚动和运行时偏移校准。
- App 内歌曲元数据覆盖编辑：标题、艺人、专辑艺人、专辑、流派、曲目号、碟片号、年份、评论和封面；关联信息读取失败时禁止保存，多值艺人/流派关系在未修改时保留。
- 歌曲技术详情：编码、码率、采样率、位深、声道、文件大小和相对文件位置；容器字段仅在媒体探针实际提供时显示。

## P0：先补齐

### P0-1 系统输出路由入口

原状：播放器内 AirPlay 图标只是占位按钮，点击后提示当前版本不支持。音频会话已经使用系统 playback 类别，并监听路由变化。

方案：直接接入系统 `AVRoutePickerView`，不实现自定义 AirPlay 协议。保留系统控制中心路由能力，并在真机验证 AirPlay、蓝牙、后台播放、输出切换和中断恢复。

状态：已实现；真机 AirPlay/蓝牙/后台路由仍待验收。

### P0-2 歌曲主列表批量管理

现状：歌曲和收藏列表主要支持逐首菜单操作；集合详情已有编辑模式和批量删除。

方案：为歌曲/收藏列表增加编辑模式、选择/取消选择、全选当前已加载歌曲、批量删除和删除失败反馈。播放历史继续保留已有的清空历史语义，不把“删除历史条目”误做成删除歌曲。

状态：已实现；当前“全选”范围是当前已加载的歌曲，分页后可继续选择新加载内容。

## P1：核心体验完善

### P1-1 歌词

- 读取音频内嵌歌词。
- 读取同名 `.lrc` 文件。
- 支持普通歌词和时间轴歌词、当前行高亮、自动滚动和偏移调整。
- 支持手动粘贴/编辑歌词。
- 首版保持本地离线，不引入在线歌词服务。

状态：已实现。歌词保存在资料库覆盖值中；同名 `.lrc` 仅在音频没有内嵌歌词时作为导入 fallback。真机播放过程中的时间轴同步仍需人工验收。

### P1-2 歌曲元数据编辑

已实现 App 内覆盖值：标题、艺人、专辑艺人、专辑、流派、曲目号、碟片号、年份、评论、歌词和封面。覆盖值通过资料库事务持久化，不写回原始音频标签；元数据服务采用完整替换语义，省略的标量/关系会清除，封面通过保留/移除/替换显式控制；编辑器会先读取完整关系再保存。恢复文件原始信息和 MP3/FLAC 标签写回仍属于后续能力。

状态：已实现；封面文件采用 App 托管的内容寻址存储，元数据事务失败时会清理本轮新建且尚未被资料库引用的封面文件；启动维护会按资料库所有权回收历史孤立封面，非合法或哈希不匹配文件会保留。

### P1-3 技术详情

歌曲详情页已展示编码、码率、采样率、位深、声道、文件大小和相对文件位置；缺失字段会被省略，不显示占位符。当前固定 VLCKit 探针没有公开容器格式字段，因此容器不宣称为已实现能力。

状态：部分实现；文件大小和相对位置只在本地导入时可用，旧资料库记录可能没有这些值；容器格式等待探针提供稳定字段后再接入。

### P1-4 重复导入策略

生产导入和 Documents 扫描统一固定使用 `.skip`；底层导入协议当前只实现跳过/报告。设置页已收敛为只展示“跳过已有内容”，不再提供尚未接通的替换和保留副本选择器。

状态：已明确收敛；`replaceExisting`/`keepBoth` 仍作为未来设置数据兼容值保留，但不会被 UI 宣称为当前可用，也不会改变生产导入行为。

### P1-5 删除和文件管理语义

- 明确区分“从资料库移除”和“删除本地文件”。
- 当前删除会移除资料库记录和 App 托管副本，保留共享 Documents 原文件；失败会通过现有删除错误反馈呈现。
- 撤销/最近删除、文件重命名、移动和整理尚未实现，不能把当前删除描述为可撤销。

状态：删除语义和失败反馈已实现；撤销/最近删除及文件管理操作仍是后续 P1/P2 工作。

## 明确不属于当前本地播放器范围

Apple Music、云同步、播客、电台、CarPlay、Siri、服务端歌单、Ampache/Subsonic 和视频界面目前在产品边界外，不应和本地播放器 P0 缺口混合推进。
