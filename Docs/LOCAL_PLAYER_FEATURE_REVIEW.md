# 本地播放器功能 Review

审查日期：2026-08-14<br>
审查基线：`main` / `87863a2`<br>
目标：补齐本地音乐播放器的日常使用闭环，区分已实现、未接通和明确不在范围内的功能。

## 当前已实现

- 本地文件和文件夹导入、Documents 自动补扫、内容哈希去重、元数据和封面读取。
- 歌曲、收藏、播放历史、专辑、艺人、流派和文件夹浏览。
- 搜索、排序、分页、刷新，以及专辑/艺人/集合详情页的歌曲操作。
- 歌单创建、重命名、删除、添加/移除歌曲和排序。
- 播放队列、播放/暂停、上一首/下一首、拖动进度、音量、静音、随机和重复。
- 播放速度、运行时均衡器、睡眠定时器、后台音频、锁屏 Now Playing 和系统远程控制。
- 单曲删除、集合歌曲批量删除；删除会移除资料库记录和 App 托管副本，但保留共享 Documents 原文件。

## P0：先补齐

### P0-1 系统输出路由入口

原状：播放器内 AirPlay 图标只是占位按钮，点击后提示当前版本不支持。音频会话已经使用系统 playback 类别，并监听路由变化。

方案：直接接入系统 `AVRoutePickerView`，不实现自定义 AirPlay 协议。保留系统控制中心路由能力，并在真机验证 AirPlay、蓝牙、后台播放、输出切换和中断恢复。

状态：已实现；真机 AirPlay/蓝牙/后台路由仍待验收。

### P0-2 歌曲主列表批量管理

现状：歌曲和收藏列表主要支持逐首菜单操作；集合详情已有编辑模式和批量删除。

方案：为歌曲/收藏列表增加编辑模式、选择/取消选择、全选当前已加载歌曲、批量删除和删除失败反馈。播放历史继续保留已有的清空历史语义，不把“删除历史条目”误做成删除歌曲。

状态：已实现；当前“全选”范围是当前已加载的歌曲，分页后可继续选择新加载内容。

## P1：核心体验完善

### P1-1 歌词

- 读取音频内嵌歌词。
- 读取同名 `.lrc` 文件。
- 支持普通歌词和时间轴歌词、当前行高亮、自动滚动和偏移调整。
- 支持手动粘贴/编辑歌词。
- 首版保持本地离线，不引入在线歌词服务。

### P1-2 歌曲元数据编辑

当前 `Track` 是不可变模型，资料库服务没有元数据更新接口，元数据读取协议也是只读。

建议先做 App 内覆盖值：标题、艺人、专辑艺人、专辑、流派、曲目号、碟片号、年份、评论和封面，并提供恢复文件原始信息。写回 MP3/FLAC 标签作为后续能力，需要格式写入、权限、备份和失败回滚。

### P1-3 技术详情

`Track.technicalInfo` 已经保存容器、编码、码率、采样率、位深和声道，但歌曲详情页目前只展示标题、艺人、专辑和时长。应补充格式、编码、码率、采样率、位深、声道、文件大小和相对文件位置。

### P1-4 重复导入策略

设置界面已经展示“跳过已有内容、替换已有内容、保留重复副本”，但正式导入和 Documents 扫描仍固定使用 `.skip`，当前底层导入协议也只实现了跳过/报告。

应暂时隐藏未生效的选项，或先设计支持内容寻址 ID、替换事务和副本关系的数据模型，再真正接通替换/保留副本。

### P1-5 删除和文件管理语义

- 明确区分“从资料库移除”和“删除本地文件”。
- 增加撤销/最近删除或至少提供明确的删除结果反馈。
- 后续补充文件重命名、移动和整理。

## P2：增强功能

- ReplayGain。
- 无缝播放。
- 淡入淡出。
- M3U 播放列表导入/导出。
- 将当前播放队列保存为歌单。
- 按格式、流派、播放次数、最近添加等条件筛选。
- 本地资料库备份/恢复。

## 明确不属于当前本地播放器范围

Apple Music、云同步、播客、电台、CarPlay、Siri、服务端歌单、Ampache/Subsonic 和视频界面目前在产品边界外，不应和本地播放器 P0 缺口混合推进。

## 建议实施顺序

1. 系统 `AVRoutePickerView` 和真机路由验证。
2. 歌曲/收藏列表批量选择、全选和删除。
3. 元数据覆盖编辑。
4. 本地歌词 MVP。
5. 技术详情和重复导入策略。
6. ReplayGain、无缝播放、M3U 等增强功能。

## 验证边界

架构检查、工程列表和差异格式检查应作为每次提交的基础验证。AirPlay、蓝牙、后台音频和 VLCKit 格式兼容性必须在真实 iPhone/iPad 上验证，不能用 Simulator 结果替代。
