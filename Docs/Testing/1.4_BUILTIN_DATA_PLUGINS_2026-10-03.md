# 现有歌词与歌曲信息的插件拆分验证

当前 checkout：MusicPlayer，feature/1.4.0_dev。本次新增 MusicFreeBuiltinDataPlugins，六个独立 product/target：LRCLIB 歌词、Metadata Server 歌词，以及 MusicKit、MusicBrainz、Metadata Server、Discogs 歌曲信息。

旧 LocalMediaAdapter Provider 和原调用入口保留；不迁移旧设置、旧同意或旧记录。新插件默认 disabled/loadBlocked，沿用现有插件管理入口分别启用、允许加载和授权；应用隐私同意仍是独立前置条件。缺少部署配置的服务保留 descriptor，并由 registry 显示不可用。

## 完成内容

- 数据插件只依赖公共 SDK 和包内 Foundation/CryptoKit 支持；MusicKit target 另外使用系统 MusicKit。没有对旧 LocalMediaAdapter、Core、Runtime 或 UI 的依赖。
- HostBridge 注册实际服务工厂，AppContainer 将其与原有参考插件一起装入 Runtime；注册不创建客户端、不联网。
- 原文歌词通过宿主 TrackLyrics 解析，保留中文、LRC 时轴与 offset。
- HTTP metadata 保留原响应/详情/封面处理、节流、错误代码、HTTP 状态及 Retry-After。候选匹配沿用宿主 MetadataEnrichmentMatcher，字段 patch 仍按请求过滤；本地专辑与目录专辑不同不会直接丢弃候选。
- MetadataPlugin 增加带默认实现的系统授权查询/请求方法，MusicKit 权限经宿主桥传递。可恢复服务错误后的授权检查仍允许重试，关闭或撤权继续阻断。
- 插件只使用查询已有时长，不接收库 item ID 或本地路径；Metadata Server 旧 Provider 的可选文件重 probe 留在旧入口。
