# 多语言全文检查（2026-10-17）

应用支持英语、简体中文、法语、德语、西班牙语、日语，沿用应用内语言选择。

## 检查与修复

- 检查 App、Packages 与 thirdpart/ExtendsPlugins 下的 380 个产品 Swift 文件；排除测试、缓存和测试支持模块。
- 补齐 113 个已有资源键缺少的法、德、西、日语翻译。
- 新增 226 个资源键，其中 35 个用于原生界面与插件，191 个用于内置文档。
- 插件总览、详情、设置入口、专用设置页和通用配置表单统一在显示时解析名称与字段标题；包含占位文本、开关标签和无障碍标签。
- 覆盖 DSP、元数据、歌词、在线来源和参考插件，包括网易云音乐、QQ 音乐扩展插件的组合名称及配置字段。
- 插件诊断中的生命周期代码解析为翻译后的状态；其他诊断保留代码并显示翻译后的错误说明。
- 内置 LRCLIB 隐私说明和 Google Drive 设置指南使用同一字符串资源渲染，保留文档内容、链接、代码、复制按钮与检查清单。英语文档的可见文字与原文经归一化比较一致。
- 新增键与现有键冲突的两组 Xcode 自动符号已按键禁用生成，不影响字符串查询。

用户填写的名称、歌曲和歌词内容、文件名、协议标识符、错误代码及示例配置值保留原文。外部网站和系统界面由其各自提供方管理。

## 防止遗漏

`python3 Scripts/check_localization.py` 现在同时检查：

- 六种语言的覆盖、翻译状态、重复键、转义与格式参数；正确区分正文百分比和格式参数。
- 直接调用、中文条件分支、预设表、状态表、图标名称及插件入口的资源键。
- 插件名称、配置字段、组合名称，以及显示边界遗漏的语言解析。
- HTML 模板键、未提取的正文和无障碍属性，以及各语言的 HTML 结构、链接和技术值一致性。

静态扫描依靠源码模式，不能替代所有运行时路径和逐页视觉检查。
