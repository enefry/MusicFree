# 手机录屏场景的模拟器切歌验收

2026-10-02，当前 `feature/1.4.0_dev` 工作区。用户要求使用模拟器测试。

结论：已修复本地压缩／混合格式被拒绝平滑切歌的问题。录屏中的两组曲目、三种设置共 6 个原始失败用例全部通过；最终模拟器回归为 81 个测试函数、217 个实际用例通过，零失败、零跳过。原有换格式 `-10868` 崩溃回归同样通过。本轮未安装新真机版本。

## 修复内容

- 本地单／双声道曲目解码后统一转换到 48 kHz 双声道 Float32 总线，支持录屏中的 8 kHz WAV → 16 kHz WMA Pro → 44.1 kHz Musepack。每曲 DSP 仍在转换前处理原始格式。
- 压缩格式以实际解码 EOF 确认边界，不用估算时长截断。每槽预读最多 3 秒加两个 8192 帧块，使最长交叉淡化窗口开始前可以确定边界；两个立体声 PCM 环形缓冲合计约 2.45 MiB，不包含解码器／转换器开销。
- 换格式及衔接后变速／seek 重建时先停止音频引擎、释放旧格式资源，再重新连接输出链，避免沿用已准备的格式。
- 空音频、损坏文件或不支持的下一曲准备失败时，保持当前曲目可播放；不再无限等待空音频输出。

## 环境与输入

- MusicFree Regression，iPhone 17 Pro，iOS 26.5，arm64。
- UDID：`C3DA6A33-6237-4B7E-ADFE-7E429DC54B69`。
- MusicFree Debug App 测试宿主，复用工程 `.noindex/DerivedData`。
- WMA Pro 和 Musepack 使用上一轮从测试 App 取出的原始文件；BVT 使用同样的 30 秒、8 kHz、单声道、440 Hz、幅度 0.08 的 WAV 信号。
- 三份输入保存在 `.noindex/artifacts/phone-smooth-recording-latest/`，复制到模拟器 App 的 `Documents/PhoneTransitionFixtures/`；没有把外部音频加入源码资源。

## 实际结果

| 场景 | 无缝播放 | 1 秒交叉淡化 | 3 秒交叉淡化 |
| --- | --- | --- | --- |
| 8 kHz 单声道 BVT WAV → 16 kHz 单声道 WMA Pro | 通过 | 通过 | 通过（实际 2 秒） |
| 16 kHz 单声道 WMA Pro → 44.1 kHz 双声道 Musepack 7 | 通过 | 通过 | 通过（实际约 1.984 秒） |

六个用例都先起播，再 seek 到前曲末尾 4 秒，随后准备下一曲。全部 `rejected=none`、`commits=1`、`fallback=false`，每次提交匹配原准备票据，后曲为 `.playing`，真实主混音器采集到非零音频。每组还执行后曲 1.5 倍速 → seek 2 秒 → 采集，以及恢复 1 倍速 → seek 2 秒 → 采集，验证曲目身份与实际输出。

下表为 48 kHz 源渲染时钟的提交／退役帧，不是扬声器输出时刻：

| 场景 | 无缝提交／退役 | 1 秒提交／退役 | 3 秒设置提交／退役 |
| --- | --- | --- | --- |
| BVT → WMA Pro | 192000 / 192000 | 144000 / 192000 | 96000 / 192000 |
| WMA Pro → Musepack | 190482 / 190482 | 142482 / 190482 | 95241 / 190482 |

现有策略把交叠上限限制为两槽有效长度各自的一半。因此 seek 到末尾约 4 秒后，3 秒设置实际约为 2 秒。这 6 个用例不能单独证明完整 3 秒淡化。独立 7 秒 ALAC 压缩音频测试在开始时无可靠 PCM 长度，以后续 EOF 得到 336000 帧，交叉淡化提交为 192000 帧、退役为 336000 帧，确认完整 144000 帧／3 秒交叠；无缝模式提交为 336000 帧。两种模式均通过，内部无信号区间最长 0.020833 ms，小于 10 ms 断言阈值。

| 最终回归范围 | 测试函数／实际用例 | 结果 |
| --- | --- | --- |
| App 宿主原始录屏曲目 | 1 / 6 | 全部通过 |
| FFmpeg 适配器完整测试 | 72 / 190 | 全部通过；包含格式、CUE、转码、远程播放、输出生命周期及 33 个衔接用例 |
| Coordinator 与设置策略 | 8 / 21 | 全部通过 |
| 总计 | 81 / 217 | 零失败、零跳过、零 expected failures |
| C 数值测试，AddressSanitizer + UndefinedBehaviorSanitizer | 19 个用例 | 全部通过，包括 3 个后到 EOF 边界与 10001 个相关信号峰值采样 |

衔接用例还覆盖混合格式四曲连续槽位复用，保证最多两个活动 DSP、每曲正确退役且内部无声小于 10 ms；换格式崩溃回归覆盖 8/16/44.1/48/96 kHz、单／双声道、正反顺序、有／无后置效果节点，4 个参数用例共 24 次播放均通过。

## 修复前证据与调试过程

原始验收结果包 `phone-smooth-mixed-formats-simulator.xcresult` 为 3 个测试函数、11 个实际用例：5 通过、6 失败、0 跳过。六个录屏组合的 `prepareNext` 均返回 `unsupported_capability`，没有 handoff。后续普通加载成功不能抵消当时的平滑切歌失败。

修复过程中的扩展测试曾因新增六声道测试夹具使用 Apple 仅支持单／双声道的按声道数初始化方式而崩溃／失败；夹具改为显式声道布局后，降级测试和最终完整回归均通过。该失败不是原始 `-10868`。WMA seek 仍有 `asf_read_pts failed` 日志，实际 seek 后音频和 EOF 均通过断言。

## 测试入口与复跑

`AppTests/FFmpegDevicePlaybackTests.swift` 中的 `phoneRecordingSmoothHandoff(_:_:)` 是原始样本验收入口。只有 App Documents 中存在专用 `PhoneTransitionFixtures` 目录时启用；目录存在但缺少样本会直接失败。本轮三份样本齐全，六个参数组合均实际执行，没有跳过。需复跑原始样本时先将上述三份输入复制到该 App Documents 子目录。

```sh
zsh .noindex/coordination/with-b-shared-lock.sh xcodebuild \
  -project MusicFree.xcodeproj -scheme MusicFree -configuration Debug \
  -destination 'platform=iOS Simulator,id=C3DA6A33-6237-4B7E-ADFE-7E429DC54B69' \
  -derivedDataPath .noindex/DerivedData -parallel-testing-enabled NO \
  '-only-testing:MusicFreeTests/FFmpegDevicePlaybackTests/phoneRecordingSmoothHandoff(_:_:)' \
  '-only-testing:MusicFreeFFmpegAdapterTests' \
  '-only-testing:PlaybackTransitionTests' \
  test
```

## 证据与边界

- `.noindex/logs/phone-smooth-mixed-format-final.log`：最终完整回归；`PHONE_TRANSITION` 包含每组提交次数、播放状态、输出帧数、能量与交叠帧数。
- `.noindex/artifacts/phone-smooth-mixed-format-final.xcresult`：最终完整结果包。
- `.noindex/artifacts/phone-smooth-mixed-format-fix/final-summary.json`、`final-tests.json`：摘要与实际参数用例树；摘要顶层 81 为函数数，设备配置下 217 为实际执行数。
- `.noindex/logs/phone-smooth-mixed-format-numerical.log`：C 数值与 sanitizer 结果。
- `.noindex/artifacts/phone-smooth-mixed-format-fix/production.diff`：本轮生产代码修复相对于开始时工作区的差异。

这是 App 测试宿主内对真实 AVAudioEngine 输出和引擎 handoff 的验收；Coordinator 使用独立测试验证调度，未覆盖资料库 UI 驱动的端到端队列流程。

原始 WMA 尾部约 2.210 秒、Musepack 开头约 1.096 秒低于 −45 dB；修复不自动裁剪文件本身的静音，也不声称通用编码器 padding 已被去除。网络衔接、CUE 重叠、非 1 倍速衔接、不兼容声道布局以及未声明保持时序的 DSP 仍使用普通播放降级。模拟器信号阈值数值不等于手机录屏的前后对比。本轮未安装新真机版本、未进行听感、锁屏／蓝牙／AirPlay 验收或 Archive。
