# 声道均衡插件开发规格

状态：首个开发版已实现，DSP 数值测试、UIKit 设置保存测试、模拟器实际 FFmpeg/AVAudioEngine 离线输出测试通过。比例映射和默认强度按用户确认配置；自动检测、平滑和相位保护参数已用于首版，仍需真机听音和性能验证。证据与待验证项见 [开发版验证记录](../Testing/Stereo_Balance_Plugin_Validation.md)。

## 目标与已确认配置

降低歌曲局部左右声道差异，同时让用户限制声场收窄程度。文件内容集中在单侧时，给另一侧混入有限的音乐内容，不追求所有歌曲都恢复相同音量。

**用户显示的强度是实际混入百分比的两倍。默认显示 20%，实际混入比例上限 10%。**

| 显示强度 | 实际混入比例 | 固定模式宽度 | 含义 |
| ---: | ---: | ---: | --- |
| 0% | 0% | 100% | 保留原始左右声道 |
| 20%（默认） | 10% | 80% | 轻度均衡 |
| 30% | 15% | 70% | 中度均衡 |
| 50% | 25% | 50% | 较明显地集中声场 |
| 100% | 50% | 0% | 固定模式为单声道 |

配置持久化使用显示值；只在构造 DSP 参数时换算一次。内部计算 `pMax = strengthPercent / 200`，范围 `[0, 0.5]`，宽度 `w = 1 - 2p`。不要在 UI 和 DSP 各除一次，也不要把显示 20% 直接当作实际混入 20%。

## 插件和设置界面

插件名「声道均衡」，ID 为 `builtin.dsp.stereoBalance`，原生 DSP、离线执行。插件默认关闭；默认参数为自动调整开启、显示强度 20%。加载和启用遵循现有内置离线插件的独立开关与授权流程。

入口「设置 → 插件 → 声道均衡」。在内置 UIKit 设置 companion 中提供两个主要控件：

| 控件 | 默认 | 行为 |
| --- | --- | --- |
| 自动调整 | 开启 | 开启时按失衡程度调整；关闭时始终使用固定比例 |
| 强度滑块 | 20% | 自动模式标题「最大均衡强度」；固定模式标题「均衡强度」 |

滑块显示 0–100%，以 1 个百分点步进，右侧显示整数百分比。首版复用现有 slider 和配置提交机制，提供显示 20%、30%、50% 的快捷选择及「恢复默认参数」。VoiceOver 使用同一显示单位和步进，不读内部混入系数。

界面只使用显示强度；不要同时放两个含义相近的百分比让用户换算。辅助文案：

- 自动模式：「仅在左右声道差异明显时调整，强度不会超过设置值。」
- 固定模式：「持续混合左右声道，数值越大，声场越集中。100% 为单声道。」
- 滑块端点：「原始」和「单声道」。自动模式补充：「100% 允许最大调整到单声道，并非始终输出单声道。」
- 生效提示：「播放中修改后，请暂停再继续播放，使新设置生效。」
- 恢复默认参数：仅恢复 `automatic=true`、`strengthPercent=20`，不改变启用、加载授权、可见性或其他插件设置。

插件关闭时允许预先设置参数。加载失败时显示现有错误与重试操作；保存失败保留草稿，并区分「未保存」与「已保存」。不把配置已保存当作音频已应用，不显示未经宿主确认的「已生效」状态。

拖动过程中本地更新数值，松手保存；快捷选择和开关直接提交。保存序列不得用旧值覆盖更新的用户意图，页面重新观察数据不得重置正在拖动的滑块。使用现有 SettingsValueSlider/PluginSettingsModel，不为本插件建立另一套 UserDefaults。

## 配置契约

`PluginConfigurationSchema` 使用版本 1：

| 键 | 类型 | 取值/缺省 |
| --- | --- | --- |
| `strengthPercent` | number | 有限数值，0–100，缺省 20 |
| `automatic` | flag | 缺省 true |

示例配置值：`strengthPercent = .number(20)`、`automatic = .flag(true)`。启用、加载许可、可见性和处理位置仍由 `PluginPreference` 管理，不重复写入 configuration。

UI 提交整数显示值；DSP 接受范围内有限小数，避免 UI 步进成为音频 API 的限制。明确的 0 必须保留为 0，不能因缺省处理变回 20。负值、超过 100、NaN/Infinity 或错误类型均拒绝，不悄悄钳制成另一个合法配置。未知字段沿用 SDK 校验策略。

初版仅支持 `.perTrack`，默认每轨；不展示不可执行的总线选项。单声道及超过两声道的输入透传，不把多声道前两个通道默认解释成左右。不同格式切换须重新 prepare。

## PCM 处理

对同一帧先读取原始 L/R，再同时计算两个输出，避免右输出使用已经写过的左输出：

```text
Lout = (1 - p) * L + p * R
Rout = (1 - p) * R + p * L
0 <= p <= pMax <= 0.5
```

混音保持采样率、声道数、帧数和时间戳，不增加前视缓存、延迟、尾音。每一输出是当前帧两个输入的凸组合，跨声道最大绝对样本值不应超过输入该帧的最大值。弱声道的单独峰值可以增加，这是混入音乐内容的预期结果。

不做分声道 AGC、不单独放大弱侧、不做硬削波和额外响度归一化。混音可能降低整体能量，尤其是反相素材；本次试听使用的整体 RMS 对齐不属于插件算法。

### 固定模式

`p=pMax`，整首歌曲采用同一交叉比例，与已提供的 10%/15%/25% 固定试听一致。显示 100% 时输出 `(L+R)/2`，左右相同。反相内容在固定高强度下可能抵消；这是单声道混合的固有结果，自动保护不能悄悄改变用户明确选择的固定比例。

显示 0% 或输入 L/R 完全一致时保持输入样本，避免无效浮点运算引入变化。固定模式不用启动分析器。处理器参数不可变，配置更新沿用宿主重新安装机制。

### 自动模式

自动模式的显示强度是最大值，不是最小值，也不是每时每刻的实际比例。检测使用原始输入，避免输出反馈使比例反复增减。第一版不开放「最大分贝差」控件；内部候选目标为 6 dB，使均衡素材自动回到接近原声。与早期高强度评估中的 2.5 dB 目标区分开。

候选处理步骤：

1. 用采样率换算的 100 ms 指数平滑估计左右能量 `PL/PR` 及互相关 `C`。按持续样本计数，每约 10 ms 更新一次控制值；跨 buffer 保留计数，不以宿主 buffer 长度作为时间步长。
2. 整体 RMS 低于 -50 dBFS 时不依据声道比值作决策，冻结控制目标；零信号不得产生 NaN 或极端增益。对分母使用受控 epsilon。
3. 原始声道差不超过 6 dB 时目标混入为 0。超过时计算满足目标的最小混入比例，并限制到 `pMax`。达不到目标就接受残余差异，不越过上限。
4. 自动模式检查预计混合能量和差异；候选混音若使差异更大，目标退回 0。对强反相/近反相输入，限制到预计整体能量损失不超过 3 dB 的比例；如果无法可靠计算，平滑退回 0。该保护仅约束自动模式。
5. 比例增加使用约 100 ms、减少使用约 1.5 s 的平滑时间常数，逐帧或按分析段内插，始终保持在 `[0,pMax]`。这些是时间常数，不是保证在该时长内完全到达目标。

候选混音的能量可由估计量计算：

```text
a = 1 - p; b = p
PLout = a*a*PL + b*b*PR + 2*a*b*C
PRout = a*a*PR + b*b*PL + 2*a*b*C
lossRatio = (PLout + PRout) / (PL + PR)
```

正反相都不能直接假设声道差随 p 严格单调。求目标比例时解上述能量比对应的二次式，选 `[0,0.5]` 内最小可行根，再应用强度上限、能量损失约束及改善检查；不要对任意反相素材直接套单调二分。单侧输入则应复现 `20log10((1-p)/p)` 的差异。

首版在起播/seek/新轨第一次检测到有效信号时，按原始输入计算初始比例；不直接强制使用 `pMax`。因此单侧开头最多取用户上限，均衡/等幅反相开头可保持 0。默认实际 10%，不能沿用最初实际 42.5% 的起播值。检测状态与当前比例随相应生命周期重置。

相位保护约束根据平滑能量估计得到的目标比例；输入突然变化时，当前比例仍按 release 时间平滑下降，因此不保证任意瞬间或任意窗口的能量损失严格小于 3 dB。固定模式遵循用户指定比例。

## 生命周期和宿主接入

处理器存储只归属一个串行解码队列。正式播放、试听、crossfade 当前轨/下一轨使用独立实例，互不共享检测、控制或 reset 状态。每轨处理在解码后、格式转换与过渡混音前进行，声明零 latency/tail，保留现有 `preservesTiming: true` 接线。

prepare 分配或初始化必要状态；process 内无设置读取、日志、网络、锁、await 或动态分配。空 buffer 是 no-op，格式不一致按 SDK 抛错并走已有链的失败旁路。非有限输入按已有回滚/旁路策略处理，不能污染下一块状态。

| 事件 | 行为 |
| --- | --- |
| 首次加载/新曲 | 独立 prepare，按模式初始化 |
| 暂停/继续 | 同一实例通常保留状态；若有待安装配置则替换实例 |
| seek、stop、重配置、路由/媒体重置 | 通过实际宿主 reset/重建路径清空检测和控制状态 |
| 过渡准备/取消 | 下一轨独立实例；取消的实例及状态不可泄漏到下一次准备 |
| 修改强度/模式/启用 | 保存配置；播放期间的重新安装延迟到输出停止 |
| 撤销许可/关闭插件 | 关闭现有 permission gate；已排队 PCM 不回写 |

当前宿主在配置改变时会先关闭旧处理 gate，再等待停止后安装新处理器，因此不能承诺等候期间旧效果一直保留。已解码 PCM 仍可能含旧效果，直到队列耗尽。启用、关闭及参数变化的可听生效时间需通过实际 FFmpeg 输出验证。

首版界面明确要求暂停再继续，不自动中断用户播放，也不临时 seek 到原位置。无缝即时调参需要额外宿主机制，本规格不把它算作已支持。并且「参数平滑」只描述同一自动处理器运行中的比例变化，不是播放中热更新已经实现。

## 验收矩阵

| 类别 | 必须确认 |
| --- | --- |
| 映射与边界 | 0→0、20→0.10、30→0.15、50→0.25、100→0.50；0 不被缺省覆盖；非法参数拒绝 |
| 固定信号 | L=R 透传；单侧公式；左右互换对称；固定 100% 左右相同；每帧跨声道峰值不增加 |
| 固定试听 | 同一 Float32 源的 10%/15%/25% 输出与参考交叉混音一致；RMS 对齐只用于试听文件 |
| 自动上限 | 所有帧的 p 均不超过用户上限；包含起播、seek、静音、突变和恢复；默认未强制达到 3 dB |
| 自动保护 | 均衡输入回到原声；强反相、近反相、单侧近静音、弱侧底噪、左右来回切换；不反复抽动或额外放大 |
| 时间一致性 | 44.1/48/96 kHz；同样输入按多种 buffer 长度送入，结果在数值容差内一致 |
| 生命周期 | 正式/试听/过渡实例隔离；seek、路由变更、取消下一轨、开关和权限撤销；无旧状态叠加 |
| 保存/UI | 默认关闭及默认 20%；保存/重启恢复；快选与滑块一致；拖动草稿稳定；保存失败和快速连续编辑；VoiceOver |
| 生效时机 | 实际 FFmpeg PCM 验证播放中修改的延迟及暂停/继续后的应用；关闭 gate 与排队音频边界 |
| 真机听音 | 耳机、蓝牙、扬声器的开头/后段、反相素材、换曲和过渡，无可辨识爆音或明显声场摇摆 |
| 性能 | 比较同素材关闭/开启时 CPU 与链预算，不触发连续超预算旁路；没有测量前不宣称特定耗电/CPU 开销 |

单侧默认固定 10% 的理论左右差约 19.08 dB。对提供的文件，开头 5 秒实际结果约 19.10 dB；15% 约 15.08 dB；25% 约 9.55 dB。保留这些残余差异是限制混入比例的预期取舍，不应为了满足旧的 3 dB 目标偷偷提高强度。

## 开发顺序与证据

1. 实现参数映射、固定处理器和单侧/反相/分块数值验证，复现已经确认的试听比例。
2. 加入每轨注册、配置保存和 UIKit companion，验证默认、保存及生效边界。
3. 实现自动检测、平滑和能量保护；用相同素材生成自动/固定试听，定稿候选阈值。
4. 实际 FFmpeg/AVAudioEngine 导出 PCM 与生命周期验证；真机听音及性能测量。

各步骤分别记录实现、数值测试、Simulator 输出和真机听音结果。首个开发版已完成实现、数值测试、设置保存测试、模拟器真实引擎离线输出和本曲正式 DSP 试听生成；尚未完成播放中热改参数的端到端时序、过渡/路由/权限撤销回归、完整应用界面人工验收、真机听音和性能测量。

Xcode 使用工程内稳定 `.noindex/DerivedData/MusicPlayer`，SwiftPM scratch/log/artifacts 同样放 `.noindex/` 可识别子目录，不创建随机 DerivedData、不复制整个工程。开发前重新检查共享工作区改动，保留与本插件无关的已有工作。

原始评估及音频证据：`.noindex/artifacts/stereo-balance-assessment/assessment.md`。当前比例试听清单：`.noindex/artifacts/stereo-balance-assessment/mix-previews/manifest.json`。早期最大实际混入 42.5% 的自动试算只保留作比较，不作为当前默认。
