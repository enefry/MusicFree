## Implemented

1. **P0 — variable-rate seek/replay restores output.** The legacy feeder reconnects
   `playerNode -> timePitch` before scheduling PCM after a transition graph is
   removed. Its output path starts the audio engine before playing the node and
   publishes a failure if engine start fails.
2. **P1 — zero seek and EOF replay rewind.** Producer start is optional: a freshly
   opened decoder needs no seek, preserving non-Range HTTP startup. Every restart
   passes an explicit position and seeks even at zero. `play()` publishes the
   resume envelope after an EOF graph replacement, so the replacement can render.
3. **P1 — prepared next no longer destroys pause/stop fading.** `cancelNext()`
   disarms the pending handoff without rebuilding the graph or resetting gain.
   Render claims next with CAS, so cancellation releases only an unclaimed slot.
   Preparation identity is checked after awaits to prevent late arming. Idle
   producers are cancelled and awaited before ring reuse. An ongoing A/B overlap
   remains in the soft fade; hard pause retires its outgoing slot after pausing
   rendering and records `.interrupted` without replacing the active graph.
4. **P1 — failed next preparation clears its identity.** A deferred cleanup clears
   the pending operation and disarms the graph on decoder/format/preparation
   failure. The format-rejection regression also checks that A's processor is
   created only once, proving cancellation did not rebuild it.
5. **P1 — plugin authorization preserves application privacy consent.** Both UI
   entry points use `PluginConsentSettings`. Plugin permission/policy and source
   instance policy are saved independently. Neither action calls
   `acceptingPrivacyPolicy()`; existing unrelated provider consent is preserved.
   Network execution still requires the independent application privacy gate.
