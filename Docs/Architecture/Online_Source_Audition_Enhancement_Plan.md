# 在线源试听体验优化规划

状态：功能方案与原生 v2 UI 均已由用户确认，已授权 Luna 子代理实施。本文保存用户已确认的独立试听方案；正式播放器接入是另行评估的替代方案，不自动替换本文。

UI 细化与设计评审见 [功能拆解与原生 iOS UI 评审规格 v2](../Design/Online_Source_Audition_UI_Spec.md)。当前已进入实施与验证阶段；具体完成情况以本文末尾的实施状态矩阵为准。

## 目标与边界

将当前“试听／停止”升级为独立悬浮试听条、展开控制面板和临时连播列表。

已确认：应用内跨页面继续试听；试听会话保留期间以可收起的悬浮试听条替换正式播放条，任何时刻只显示一个底部播放入口；仅连播当前目录中已加载且可试听的歌曲，不自动请求后续分页。继续使用独立试听引擎，不写入正式播放队列、历史或持久化存储。

## 界面与交互

- 目录保留逐曲试听入口：播放时暂停、暂停后继续、准备中允许取消、失败可重试；下载操作独立。
- 悬浮试听条左侧提供收起，右侧提供暂停／继续和下一首；关闭不出现在悬浮条中。试听会话保留期间占用正式 Mini Player 的底部位置并隐藏正式播放条；视觉高度和左右边距复用正式 Mini Player。
- 可收起为底部右侧的小胶囊，保留曲名／状态和播放／暂停，不显示关闭按钮；点击曲名或主体恢复，不提供自由拖拽。
- 点击试听条展开面板，显示曲名、歌手、来源、已播／总时长、进度拖动、上一首／暂停／下一首和临时歌曲列表；左上和下滑只收起，右上“结束试听”才结束会话。
- 区分解析中、缓冲、暂停、播放结束和失败；错误在面板内展示并支持重试，避免重复弹窗。无可靠时长或不支持定位时禁用拖动。

## 连播与生命周期

- 启动时按当前目录展示顺序冻结当前已加载的可试听歌曲，按歌曲 ID 去重，从点击歌曲开始；该完整顺序队列在会话内保持不变。
- 切换目录、搜索、排序或加载分页不改变既有列表；点击另一首歌曲时使用该歌曲所在列表建立新会话。
- 顺序连播，不循环、不随机；上一首始终切至前一首，首尾禁用越界操作。末曲结束保留结束状态，可重播或关闭。
- 单曲失败停止自动推进，允许重试或手动下一首；重试重新获取临时播放地址。
- 试听开始暂停正式播放；启动正式播放时结束试听并关闭悬浮条；关闭试听不自动恢复正式播放。
- 应用内导航、切换标签和短暂离开 App 均不停止；进入后台保留试听会话、队列和当前位置，不主动 stop/close。系统音频中断暂停试听，之后等待手动继续。
- 来源删除、禁用、撤销授权或在线服务关闭时，停止对应试听并清空列表。

## 实现调整

- 扩展 OnlineAuditionServing：列表及起播项启动接口、暂停、继续、定位、上一首、下一首和重试；保留单曲入口作为单项列表适配。
- 扩展 OnlineAuditionSnapshot：临时列表、当前索引、歌手及来源展示信息、定位能力和结束状态。列表只保存目录元数据，当前歌曲的远程地址和认证信息按需临时获取。
- OnlineAuditionCoordinator 统一管理列表推进和引擎操作，延续操作 ID、播放 generation 校验，避免快速切换或旧回调覆盖新会话。
- 根界面持有全局悬浮入口，试听视图放入 PlayerFeature，通过试听服务驱动；根容器同时观察正式播放与试听快照，在 retained audition 期间隐藏正式 Mini Player，结束试听后按原正式播放快照恢复其表面但不恢复播放。在线源页面传入列表上下文，兼容标签栏和侧栏布局。
- 目录仅更新受影响歌曲状态；进度变化只更新试听控件。拖动期间不被播放回调覆盖，松手后提交定位。

## 验证与验收

- 控制与列表：暂停继续、定位、首尾边界、自然结束连播、末曲结束；过滤非音频和重复项；冻结列表不受分页、目录变化影响。
- 竞态与异常：连续切歌、准备中关闭、旧请求返回、定位途中切歌、地址过期和断网重试，不误播、不覆盖当前状态。
- 播放互斥：不同时出声；关闭试听不恢复正式播放；后台及权限撤销能终止解析或缓冲中的任务。
- 界面：跨页面控制、悬浮条左侧收起、紧凑胶囊展开／收起、Sheet 左上收起／下滑收起／右上结束、试听期间正式 Mini Player 隐藏及结束后的恢复、键盘、横竖屏、大字体和 VoiceOver；进度更新不导致目录闪烁或滚动跳动。
- 补充 Core／UI 行为测试，复用工程 .noindex/DerivedData 构建，并通过真实在线源验证缓冲、定位和连续播放。首版不扩大来源能力范围。

## 系统播放栏联动修订（2026-09-08）

- iOS 26 手机端将试听内容装入正式 Mini Player 的同一个 `UITabAccessory` 宿主，直接切换内容，避免标签栏缩成两侧圆钮而试听条仍全宽悬浮。
- 试听内容不再绘制第二层玻璃或重复水平边距；inline 模式保留曲名和播放，隐藏副标题、收起和下一首；系统恢复展开时恢复全部控件。
- 手动收起也在系统播放栏内呈现精简入口，避免独立胶囊与标签栏／搜索按钮碰撞。宽屏与旧系统保留原独立胶囊。
- 左侧收起符号缩为 13pt，点击范围仍为 44pt；结束试听仍只在 Sheet，正式播放仅恢复显示、不自动继续。
- 修复显式收起 Sheet 后入口可能持续隐藏，以及容器换内容时旧约束的清理。手机、旧系统和宽屏为试听保留底部内容避让。
- 定向 UI 回归 `testAuditionSharesNativeMiniPlayerSlot` 已于 iPhone 17 Pro / iOS 26.5 模拟器通过：原播放器显示、试听替换、系统 inline 收缩、回滚展开、Sheet 显式收起、手动精简入口恢复、结束试听后恢复原曲目并保持暂停。最终微调后的复跑同样通过，结果包位于 `.noindex/artifacts/audition-native-host-final.xcresult`。展开、inline、手动收起和正式播放器恢复截图分别保存在 `.noindex/artifacts/audition-native-*.png`。
- 之前的 CoreSimulator 连接错误来自沙箱访问限制，本轮已在沙箱外实际执行 UI 测试。测试在线源为失败 fixture，因此该结果证明界面与会话切换，不代替真实在线源声音、连续播放和 seek 验收。
