## 3. 共享文件和构建锁

共享锁固定路径：`.noindex/coordination/1.4-shared.lock`。先创建稳定父目录，再用单次 `mkdir` 获取锁；只有成功创建者可修改受保护文件或运行宿主 Xcode 生成/构建/测试。锁目录保存 owner（A/B、session ID）、操作及开始时间；完成或失败均释放自己获取的锁。

无法获取锁时继续独立模块/测试/文档工作，稍后重试，不阻塞等待超过 60 秒，不删除未知锁或对方锁。发现疑似遗留锁先核对 owner session 状态，不能单凭时间长认定失效。禁止持锁等待用户输入或长时间做设计推演。

共享文件读取可以并行；修改、工程生成和宿主 Xcode 验证串行。读取后到落盘前若文件已变更，重新读取并整合，不能用旧内容覆盖新改动。

复用已存在的主仓库 `.noindex/DerivedData`；独立 SwiftPM 测试分别使用固定 `.noindex/PluginSystem` 与 `.noindex/PlaybackTransitions` scratch 路径。日志/工件留在 `.noindex/`，不创建随机或系统临时 DerivedData，不清空缓存。
