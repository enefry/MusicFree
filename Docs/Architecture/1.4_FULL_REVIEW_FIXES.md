## 复审新增并修复

- 插件加载失败仅显示 failed、缺诊断且重试成功后可能残留旧诊断：增加安全错误码与成功清理，17 项 Runtime 回归包含失败→显式重试→ready。
- 多实例状态取 Dictionary.first 不稳定：按 failed/loading/running/ready 固定优先级汇总。
- 来源更换部分凭据可能生成不完整 replacement record：更换时要求所有必填 secret 同时提供；失败回收新 Keychain 记录，提交成功后才清旧记录，字段不落盘。
- 未授权 handoff 的兜底补齐同曲 generation、Now Playing 清理和旧历史完成，覆盖两种实际提交与恰好一次完成。
- 真实 AVAudioEngine tap 卸载顺序异常：tap 先移除再 detach；App 与实际 graph 回归均通过。
