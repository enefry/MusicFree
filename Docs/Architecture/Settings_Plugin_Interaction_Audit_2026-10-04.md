# 插件迁移后的设置交互梳理

本次在当前 `feature/1.4.0_dev` 工作区已有 UIKit 设置改造上补充修复，保留同工作区其他任务的修改。均衡器预设目录与曲线修复由另一个聊天处理，本次不重复实现。

## 发现与调整

| 路径 | 原因 | 修复后行为 |
| --- | --- | --- |
| 普通设置、导入转换、歌曲过渡、存储、定时计划 | 保存时统一禁用开关、菜单、滑杆、计划时间和步进器，虽然模型已支持排队，UI 仍丢弃操作 | 已加载的偏好控件保持可操作；能力限制和计划启用条件继续生效。恢复默认、系统换图标、存储维护等独立操作保留各自的执行限制 |
| 插件开关、许可、配置 | 开关排队，但许可在 busy 时直接返回，配置可能直接失败；旧保存回传还可能重绘后续开关 | 概览与详情共享 `PluginSettingsModel`，所有这些修改按同一队列处理；待保存修改覆盖在最新 Runtime 快照上，旧结果不能抹掉后续选择 |
| 插件与原设置页联动 | 仅进入页面时读取插件快照，其他设置页提交后仍显示旧状态 | 订阅设置变化，刷新 Runtime 快照；每次执行只修改当前设置中的对应字段，保留其他偏好 |
| 插件迁移适配 | 保存后再次应用原始请求，可能覆盖 SettingsCoordinator 已归一化的插件参数 | 使用保存后重新读取的设置更新 Runtime |
| 配置表单 | 输入后标题消失，失败时 reloadData 重建单元格 | 字段标题始终可见，支持动态字体；失败保留输入和控件，空配置入口隐藏 |
| 加载失败 | 插件页缺少可恢复的加载状态 | 提供加载状态、错误与重试；当前控制器可恢复 |
| 音效分析 | DSP 详情推入后台后仍订阅分析数据 | 详情显示时订阅、离开时取消；继续限制为每秒最多 4 次更新峰值/RMS |
| VoiceOver 滑杆 | 仅在 touch-up 保存，辅助功能调整没有 touch-up | 按控件实际步长调整并保存；禁用控件不会保存 |
| 账户来源表单 | 快速点击可在任务开始前创建多个提交任务；固定中文文案和部分控件缺少标识 | 保存/删除在异步入口再次检查忙碌状态，避免重复提交；固定文案接入应用语言设置，并补全控件辅助功能标识 |

插件许可仍与应用隐私许可独立。连续授权测试确认授予插件网络许可不会同意应用隐私政策。隐藏入口与停用能力继续保持独立。
