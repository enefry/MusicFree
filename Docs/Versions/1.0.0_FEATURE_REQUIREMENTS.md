# MusicFree 1.0.0 功能需求

> 文档性质：1.0.0 发布基线整理版。
>
> 当前仓库没有发现独立的 1.0.0 原始 PRD；本文件依据 1.0.0 发布提交、README、手工测试用例和 2026-08-15 功能 Review 汇总，不把后续 1.1.x 能力倒填进首版需求。

## 1. 产品目标

提供一个 iPhone/iPad 本地音乐播放器：用户可以从文件或 Documents 导入自己的音频，在本地建立资料库、编辑信息、组织歌单并播放。首版不依赖账号、流媒体目录或云端资料库。

目标平台：iOS / iPadOS 26.0 及以上。

## 2. 首版功能范围

### 2.1 导入与资料库

- 从 Files、共享 Documents 和文件夹导入本地音频。
- 启动或回到前台时补扫 Documents，避免文件共享目录中的新文件遗漏。
- 对导入内容执行内容哈希和重复检测；首版生产行为为跳过已有内容并报告结果。
- 读取可用的音频元数据、封面、内嵌歌词和同名 `.lrc` 文件。
- 资料库支持歌曲、收藏、播放历史、专辑、艺人、流派、文件夹、搜索、排序、分页和刷新。
- 详情页展示真实可用的技术信息；缺失字段不显示虚假占位值。

### 2.2 播放

- 播放/暂停、上一首/下一首、进度拖动、音量和静音。
- 随机、重复、播放速度、运行时均衡器和睡眠定时器。
- 播放队列恢复、自动切歌和播放历史记录。
- 后台音频、锁屏 Now Playing、控制中心远程控制和系统音频路由入口。
- 通过固定版本 VLCKit 适配器执行本地媒体探测和音频播放。

### 2.3 歌词与编辑

- 展示普通歌词和时间轴歌词，支持当前行高亮、自动滚动和运行时偏移。
- 支持在 App 内编辑歌词和歌曲元数据覆盖值。
- 支持标题、艺人、专辑艺人、专辑、流派、曲号、碟号、年份、评论和封面覆盖。
- 元数据覆盖写入资料库和 App 托管 artwork，不修改用户原始音频标签文件。

### 2.4 歌单与文件管理

- 创建、重命名、删除歌单，添加/移除歌曲并调整顺序。
- 支持歌曲/收藏列表的选择和批量操作。
- 区分“从资料库移除”“从歌单移除”“从播放历史移除”和删除 App 托管副本。
- 删除失败必须保留可解释的错误反馈；共享 Documents 原文件不因普通资料库删除被误删。

### 2.5 设置与系统

- 播放、外观、语言、应用图标、存储状态和维护、诊断信息设置。
- 支持 iPhone/iPad 常见尺寸、横竖屏、深色模式、Dynamic Type、VoiceOver 和键盘焦点。
- App 内集成第三方许可证与归属材料。

## 3. 非目标

1.0.0 不包含：Apple Music catalog/歌词在线补充、云同步、Ampache、Subsonic、播客、电台、CarPlay、Siri、服务端歌单、视频播放和远程 Provider 账号管理。

## 4. 数据与隐私要求

- 默认本地优先，不上传音频文件、完整资料库或绝对路径。
- 队列和歌单持久化稳定标识及用户意图，不持久化临时播放 URL、Header 或 VLCKit 对象。
- 资料库、播放队列、歌单、设置和本地歌词/封面在 App 内持久化并可跨启动恢复。
- 隐私政策和第三方许可证材料必须随发布材料提供。

## 5. 验收条件

- Core、Infrastructure、UI、VLCKit Adapter 和 App 目标可以按工程脚本生成、编译和运行测试。
- 真实 App 入口可以完成“导入 -> 资料库 -> 播放 -> 队列/历史 -> 设置”的主闭环。
- 删除、重复导入、歌词、封面、歌单、后台播放和启动恢复没有破坏性回归。
- Simulator 结果与真机门槛分开记录；AirPlay、蓝牙、真实媒体格式、长时间播放和中断恢复必须在真实设备继续验收。
